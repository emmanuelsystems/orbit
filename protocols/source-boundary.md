# Source Boundary Protocol

## Source classes

### Primary source

The exact meeting transcript or canonical meeting record being analyzed.

### Supporting source

Agenda, prep notes, previous accepted state, linked decisions, or artifacts directly relevant to the current meeting.

### Historical context

Older material used only to explain background. Historical context must not be presented as something said or decided in the current meeting.

### Excluded source

Material intentionally outside the current scope.

### Missing source

Expected evidence that is unavailable. Record it rather than silently replacing it.

## Non-substitution rule

When the requested primary transcript is unavailable:

1. stop transcript-specific conclusions,
2. report the exact missing source,
3. do not substitute an older or newer transcript,
4. continue only with tasks that do not require the missing source.

## Evidence discipline

Every important conclusion should be traceable to a source or explicitly labeled as interpretation/recommendation.
