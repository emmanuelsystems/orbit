# Mission State Promotion Protocol

Mission State is curated operating memory, not a Flight Recorder archive.

## Candidate Mission State may include

- active goals
- active experiments
- unresolved PENDING decisions
- NO-GO holds and release conditions
- GO decisions that remain operationally relevant
- commitments
- outstanding actions
- next-Orbit questions
- durable preferences explicitly relevant to the Mission Charter

## Candidate Mission State must not include by default

- full transcript text
- casual conversation
- unsupported interpretation
- superseded proposals
- sensitive credentials
- external data copied only for convenience

## Promotion gate

`candidate-mission-state.md` is candidate state.

A human must review it before its content replaces or updates `state/current.md`.

Creating a candidate file does not equal acceptance.
