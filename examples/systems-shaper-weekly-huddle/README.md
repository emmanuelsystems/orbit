# Mission 001: Systems Shaper Weekly Huddle

This is ORBIT's first real-world Mission example: a two-person recurring operating huddle between Emmanuel and David.

It is intentionally separate from ORBIT core so Systems Shaper-specific names, roles, sources, and routing conventions do not become generic product assumptions.

## Prototype lineage

The original prototype explored:

- weekly Mission State recovery
- July 31, 2026 as the reference Orbit / Flight Recorder
- decision and action reconciliation
- GO / NO-GO authority boundaries
- Firstmate orchestration
- Codex-only fallback
- durable next-Orbit Mission State

Use `config.yaml` as an example of how a real team can specialize ORBIT.
