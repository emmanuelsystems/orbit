# orbit-status

Run `./bin/orbit status <slug>`. Read the Mission Charter, accepted Mission State, and latest Orbit only. Report Flight status, GO / NO-GO / PENDING items, Flight Plan and holds, latest Orbit artifacts, and next action. Clearly distinguish accepted Mission State from candidate Mission State.
